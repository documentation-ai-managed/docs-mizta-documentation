## Core Features of Mizta

Mizta offers a robust set of features designed to streamline documentation workflows and enhance team collaboration.

<Columns cols={3}>
  <Card title="Real-time Collaboration" icon="users" href="#">
    Edit documents simultaneously with your team. See changes in real-time and track editing history.
  </Card>
  <Card title="Version Control" icon="git-branch" href="#">
    Maintain version history for all documents. Compare changes and revert when needed.
  </Card>

## Security and Compliance

Mizta prioritizes security with enterprise-grade features.

- End-to-end encryption for data in transit and at rest
- SOC 2 Type II compliance
- GDPR compliance for data privacy
- Role-based access control

## Getting Started with Features

To explore these features:

1. Sign in to your Mizta account
2. Create or access a documentation space
3. Click on "Settings" to configure integrations
4. Use the "+" button to create new documents and test features

<Callout kind="info">
  Most features are available on all plans, with advanced features reserved for Pro and Enterprise tiers.
</Callout>
