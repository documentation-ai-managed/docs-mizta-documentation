## Release History

<Update label="2024-10-15" description="v2.1.0" tags={["feature", "improvement"]}>

## New Features

- Added real-time collaboration features for team editing
- Introduced advanced search with filters and tags
- Implemented API rate limiting and usage analytics
- Added support for custom document templates

## Improvements

- Enhanced mobile responsiveness across all devices
- Improved import performance for large documentation sets
- Updated user interface with modern design elements
- Added keyboard shortcuts for common actions

</Update>

<Update label="2024-09-20" description="v2.0.0" tags={["breaking", "feature"]}>

## New Features

- Launched redesigned user interface with improved navigation

- Introduced role-based access control for enterprise users
- Implemented document version history and comparison

## Breaking Changes

- Updated API endpoints to v2 format
- Changed authentication method requirements
- Modified webhook payload structure

</Update>
