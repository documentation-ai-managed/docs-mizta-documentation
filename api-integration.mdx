## JavaScript SDK Usage

Install and use our JavaScript SDK for easy integration.

<CodeGroup tabs="Installation,Usage">
  ```bash
# Install via npm
npm install mizta-sdk

# Or via yarn
yarn add mizta-sdk
  ```
  ```javascript
const Mizta = require('mizta-sdk');

const client = new Mizta({
  apiKey: 'your-api-key-here',
  baseUrl: 'https://api.mizta.com/v1'
});

// Create a new space
async function createSpace() {
  try {
    const space = await client.spaces.create({
      name: 'My API Docs',
      description: 'Documentation for my REST API',
      visibility: 'private'
    });
    console.log('Space created:', space.id);
  } catch (error) {
    console.error('Error creating space:', error.message);
  }
}

createSpace();
  ```
</CodeGroup>

## Webhook Integration

Set up webhooks to receive real-time notifications.

<CodeGroup tabs="Setup,Payload">
  ```javascript
// Register webhook
const webhook = await client.webhooks.create({
  url: 'https://your-app.com/webhook/mizta',
  events: ['document.created', 'document.updated'],
  secret: 'your-webhook-secret'
});
  ```

## Rate Limits and Best Practices

<Expandable title="API Rate Limits" default-open="false">
  - 1000 requests per hour for free tier
  - 10000 requests per hour for Pro tier
  - Implement exponential backoff for retries
  - Cache responses to reduce API calls

## Error Handling

Handle API errors properly in your applications.

```javascript
try {
  const document = await client.documents.get('doc-123');
} catch (error) {
  if (error.status === 404) {
    console.log('Document not found');
  } else if (error.status === 429) {
    console.log('Rate limit exceeded, retrying...');
    // Implement retry logic
  } else {
    console.error('API error:', error.message);
  }
}
```
