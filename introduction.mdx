## Getting Started

To begin using Mizta, create your first documentation space. You can import existing documentation from Markdown files, Confluence, or other platforms.

<CodeGroup tabs="CLI,API">
  ```bash
# Install Mizta CLI
npm install -g mizta-cli

# Initialize new documentation space
mizta init my-project

# Import existing docs
import --source ./docs --format markdown
  ```
  ```javascript
const Mizta = require('mizta-sdk');

const client = new Mizta({
  apiKey: 'your-api-key',
  baseUrl: 'https://api.mizta.com'
});

// Create a new documentation space
const space = await client.spaces.create({
  name: 'My Project Docs',
  description: 'Documentation for my project'
});
  ```
</CodeGroup>
